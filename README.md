# API de Cadastro de usuários

## Descrição

Este projeto é uma API simples para cadastro de usuários contendo os campos:

- `nomeCompleto`
- `email`
- `cpf`

Os dados são armazenados em um banco de dados relacional e as requisições podem ser testadas via Insomnia. O banco pode ser visualizado no DBeaver.
